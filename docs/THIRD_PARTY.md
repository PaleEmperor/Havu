## Research; not bundled code or assets

- Perfect Freehand: https://github.com/steveruizok/perfect-freehand (MIT).
  Evaluated for the abandoned browser draft; not used in this native application.
- Paper.js: https://github.com/paperjs/paper.js (MIT). Evaluated, not used.
- MyPaint brushes: https://github.com/mypaint/mypaint-brushes . Brush settings are

  in the repository has the same license. No MyPaint files are redistributed.
- GDQuest Krita brushes: https://github.com/GDQuest/krita-free-brushes . The
  repository specifies CC BY 4.0 for the brush collection. Not redistributed.

The app can open these two brush repositories as external research resources.
It does not claim native compatibility with their brush engines or formats.
