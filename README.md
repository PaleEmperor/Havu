# Havu

**Open-source illustration app for Android tablets.** Draw with pressure-sensitive brushes, edit scalable vectors, and lay out illustrations, posters, and menus.

[**Download the Android APK**](https://github.com/PaleEmperor/Havu/releases/download/v0.1.0-beta.78/havu-beta.apk) · [All releases](https://github.com/PaleEmperor/Havu/releases)

## Features

- **Vector and paint layers.** Work with editable shapes, paths, and text alongside pixel painting. Reorder layers, lock them, and adjust their opacity.
- **Brushes.** Browse and customize presets with live stroke previews. Import Havu brushes and adapt MyPaint `.myb` presets, with compatibility notes and a preview before importing.
- **Vector editing.** Edit nodes, group objects, move artwork between layers, and merge matching solid fills or ink. Rotate, flip, align, and space selections.
- **Fill and cut.** Fill a shape or a gap enclosed by shapes and lines on the active vector layer. Draw loops to make multiple cutouts in the same shape.
- **Symmetry.** Mirror or repeat brush strokes as you draw. Make symmetric copies of existing vector artwork or repeat a finished stroke around its starting point.
- **Tablet controls.** Draw with stylus pressure, pan with one finger, and pinch to zoom. Map supported pen buttons to actions such as the eraser or color picker.
- **Workspace.** Move, resize, and dock panels. Adjust the UI scale and switch between projects in a working folder.
- **Project files and export.** Save editable `.havu` projects, resize the canvas, and export PNG or SVG.

## Get started

Install the APK on an ARM64 Android tablet and choose **New illustration**. The first blank project opens a short tour. You can replay it from **⋯ → Getting started**.

Havu is in beta and works offline. It has no AI features and requires no account or subscription.
